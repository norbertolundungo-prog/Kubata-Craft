# 🇦🇴 Kubata Craft

Servidor Minecraft comunitário inspirado em Angola.

## 🎮 Sobre o projeto

O **Kubata Craft** é um projeto de servidor Minecraft criado para jogadores angolanos e para a comunidade lusófona.

### Objetivos

* 🇦🇴 Criar uma comunidade Minecraft angolana
* 🌍 Receber jogadores de toda a comunidade lusófona
* 🏘️ Criar cidades e construções comunitárias
* 💰 Desenvolver um sistema de economia
* 🎉 Organizar eventos
* 🛡️ Manter um ambiente seguro e amigável

## 📁 Estrutura

```text
server.properties.example → Configuração inicial
start.sh                  → Inicialização Linux/macOS
start.bat                 → Inicialização Windows
docs/                     → Documentação
plugins/                  → Informações sobre plugins
config/                   → Configurações adicionais
```
